## Agent 回答与事实

Agent 回答可能不完整或有误。商品事实必须以业务工具结果为准。

## 规则回答与引用

规则类回答必须引用知识库文档、版本和章节。没有可靠检索结果时，Agent 必须明确表示无法确定。

## 可保存的阅读偏好

系统可以保存用户明确表达的阅读语言、主题、作者和预算等偏好。用户可以查看和删除自己的长期记忆。

## 删除长期记忆

删除长期记忆后，相应数据不得继续用于后续推荐，对应向量数据也必须删除。

## 禁止写入记忆的数据

密码、JWT、邮箱验证令牌、实时库存、实时价格和订单状态不得写入长期记忆。

## 数据保留期限

除非对应的自动清理机制已经实现并通过测试，系统不得声明具体的数据保留期限。
