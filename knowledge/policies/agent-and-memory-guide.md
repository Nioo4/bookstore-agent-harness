# Agent 与记忆使用说明

## Agent 回答与事实

Agent 回答必须以当前运行的工具结果和知识证据为依据。商品价格、库存、状态和订单信息不能从模型常识、历史对话或知识卡恢复。

## 工具权限与注册表

Agent只能调用服务端在本次请求中明确提供的注册工具，不能创建新工具、修改工具Schema、扩大权限或绕过用户确认。不同问题只开放完成该问题所需的最小工具集合；模型文本、历史消息和检索文档都不能为工具扩权。

## 规则回答与引用

规则类回答必须引用知识库文档、版本和章节。没有可靠检索结果时，Agent 必须明确表示无法从当前知识库确定该规则。

## 可保存的阅读偏好

系统只保存用户明确要求记住的结构化阅读语言、主题、作者、通常预算或排除项。临时预算和模型推断不能自动成为长期偏好。用户可以查看和删除自己的长期记忆。

## 删除长期记忆

删除长期记忆后，相应数据不得继续用于后续推荐；若该记录曾生成向量，后台清理也必须删除对应向量。

## 禁止写入记忆的数据

密码、JWT、Cookie、邮箱验证令牌、确认令牌、完整地址、实时库存、实时价格和订单状态不得写入长期记忆、RAG证据或Trace。

## 知识卡边界

书籍知识卡是内部审核的合成资料，用于适读人群、前置知识、主题和不覆盖内容判断，不代表真实出版物全文、作者观点或用户评价。书籍知识卡不能覆盖实时商品事实。
