# 演示范围常见问题

## 真实支付

当前不会真实支付，只创建模拟订单。

## 真实发货与配送时间

当前不会真实发货，不产生真实物流，也不提供真实配送时效承诺。

## 物流单号与轨迹

当前不支持物流单号或真实物流轨迹。

## 退款退货与换货

当前不支持退款、退货或换货，Agent 不得声称已经执行这些操作。

## 用户取消订单

当前不提供用户订单取消操作。

## 自动下单

Agent 不可以自动下单。系统必须先提供订单预览，并获得确认接口产生的显式确认事件。

## 缺货处理

邮箱已验证的用户可以创建补货监听。任务触发后只产生站内通知，不发送补货邮件、不生成订单预览、不创建订单且不扣减库存。

## Agent 准确性

Agent 回答不保证一定准确；商品事实以实时业务工具结果为准。知识库没有可靠结果时，Agent 必须明确说明无法确定，不得自行编造政策。
